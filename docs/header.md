# Header

- Content: `content/site.js` (`nav`, `site.applyUrl`)
- Component: `components/Header.jsx`
- Style: `styles/header.css`

Sticky nav with mobile menu, language dropdown, scroll progress bar, active-link highlight and back-to-top button.
Add a link to `nav`; its `href` must match a section `id` (e.g. `#news`). The language list comes from `i18n/index.js`.
