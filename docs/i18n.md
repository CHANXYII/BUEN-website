# Languages (EN / TH / 中文)

- English is the HTML itself. Thai and Chinese are dictionaries: `app/i18n/th.js`, `app/i18n/zh.js`.
- A dictionary maps the exact English text to its translation. Text not in the dictionary stays English.
- **Change wording:** edit the English in `src/sections/*.html` *and* the matching key in both dictionaries.
- **Add a string:** add the key to both dictionaries. It must be a text-only element (no child tags).
- The choice is saved in the browser; the first visit follows the browser language.
- Translations are machine-drafted: have a native speaker review before launch.
- Chinese is Simplified. DB Adman X has no Chinese glyphs, so Chinese uses a system font.
