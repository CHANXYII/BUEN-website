# Languages (12)

English, ไทย, 中文, 日本語, 한국어, Français, Español, Bahasa Indonesia, Filipino, Tiếng Việt, မြန်မာ, ລາວ.

- English is the text in `content/` and `components/`. Every other language is a dictionary, `i18n/<code>.js`, that maps the exact English text to its translation. Text not in a dictionary stays English.
- In components, translatable text is wrapped in `<T>…</T>` (`components/Lang.jsx`). Text from `content/` is already wrapped by the components.
- **Change wording:** edit the English in `content/` (or the component) *and* the matching key in every language file.
- **Add a string:** add the key to every language file.
- The tab title per language is the `title` key in each dictionary.
- The choice is saved in the browser; the first visit follows the browser language. Pages are built in English and switch after loading.
- Translations are machine-drafted: have a native speaker review before launch.
- Fonts: Google Sans has no Thai, Chinese, Japanese or Korean glyphs. Thai letters use DB Adman X from `styles/fonts/`, limited by `unicode-range` in `styles/base.css`, so Latin text on the Thai page stays Google Sans; Noto Sans Thai is the fallback. Myanmar and Lao use Noto Sans from Google Fonts; Chinese, Japanese and Korean use system fonts.

**Add another language:** copy `i18n/fr.js` to `i18n/<code>.js` and translate it, then import it and add one line to `LANGS` in `i18n/index.js`. The header dropdown updates by itself.
