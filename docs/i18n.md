# Languages (12)

English, ไทย, 中文, 日本語, 한국어, Français, Español, Bahasa Indonesia, Filipino, Tiếng Việt, မြန်မာ, ລາວ.

- English is the HTML itself. Thai and Chinese are dictionaries: `app/i18n/<code>.js` (th, zh, ja, ko, fr, es, id, fil, vi, my, lo).
- A dictionary maps the exact English text to its translation. Text not in the dictionary stays English.
- **Change wording:** edit the English in `src/sections/*.html` *and* the matching key in every language file.
- **Add a string:** add the key to every language file. It must be a text-only element (no child tags).
- The choice is saved in the browser; the first visit follows the browser language.
- Translations are machine-drafted: have a native speaker review before launch.
- Chinese is Simplified. Japanese and Korean use system fonts too; Myanmar and Lao use Noto Sans fonts from Google Fonts. Google Sans has no Thai, Chinese, Japanese or Korean glyphs: Thai uses Noto Sans Thai (loaded from Google Fonts), the others use system fonts.

**Add another language:** copy `app/i18n/fr.js` to `<code>.js` and translate it, then add the code to `LANGS`, `SHORT` and `HTML_LANG` in `app/i18n.js`, the file name to the list in `app/build.mjs`, and a button to the dropdown in `src/sections/header.html`.
